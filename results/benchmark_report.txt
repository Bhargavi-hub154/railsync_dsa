ACADEMIC ANALYSIS & VIVA NOTES
--------------------------------------------------------------------------------
1. String Search Insights:
   - Naive search requires backtracking: when a character mismatch occurs after
     several matches, the text pointer rewinds, causing O(n * m) worst-case time.
   - KMP utilizes the Longest Prefix Suffix (LPS) array to advance without any
     backtracking in the text pointer, strictly achieving O(n + m) time complexity.
   - In pathological cases with heavy prefix repetition, KMP provides orders of
     magnitude faster execution compared to Naive search.

2. Sorting Insights:
   - Standard deterministic QuickSort (pivot at first/last index) degrades to O(n^2)
     on already-sorted or reverse-sorted datasets, causing call-stack overflow.
   - Randomized QuickSort selects a pivot uniformly at random, ensuring balanced
     partitions and preserving expected O(n log n) performance across all inputs.
   - Java's built-in Arrays.sort uses Dual-Pivot QuickSort with JVM assembly-level
     intrinsics and JIT optimizations, serving as an optimal industry baseline.

3. Benchmarking Considerations:
   - Measurements use System.nanoTime() for high-resolution elapsed duration.
   - Exact timings vary depending on CPU frequency scaling, JVM JIT warmup,
     operating system scheduler interrupts, and garbage collection passes.
